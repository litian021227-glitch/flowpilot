# FlowPilot 项目完成状态

## 已完成

- 产品首页与 `/#workbench` 工作台入口
- 任务中心：Agent 任务提交、任务列表、任务详情接口、手动创建和状态更新接口
- Agent：OpenAI Responses API、知识检索、执行轨迹、无密钥 fallback
- 知识库：文档切分、关键词检索、文档与知识片段查询接口
- 审批流：审批请求持久化、通过/拒绝、任务状态更新
- 可观测性基础：Agent runs、audit events、工作台 summary 接口
- Supabase：核心表、索引、幂等 policy、workspace_members 和角色 RLS 基础
- Render：Blueprint、健康检查、生产 CORS 域名、请求限流配置
- Auth 基础：Supabase Auth REST 登录、注册、会话恢复、退出和前端路由保护；后端 `REQUIRE_AUTH` 开关
- 面试交付材料：架构说明、演示流程和追问准备

## 仍需开发才能称为生产版

### 前端

- Supabase Auth 仍需在 Supabase 控制台配置邮箱确认策略并完成真实账户验收
- 工作区切换、成员列表、角色管理和邀请流程
- 任务详情页：完整结果、来源引用、运行时间线和审批历史
- 知识库上传：PDF、Word、Excel、对象存储和删除/重新索引
- 审批详情：结果预览、审批意见、拒绝原因和二次确认
- 错误边界、加载骨架、空状态、分页、搜索和移动端完整适配

### 后端

- 从“首个 workspace”切换为基于当前用户/工作区的授权上下文
- 接入 Supabase JWT 校验，禁止匿名访问业务接口
- 统一请求体大小限制、结构化日志、错误码和 request id
- Agent 工具调用白名单、超时、重试、取消任务和幂等键
- 文件上传与异步索引队列，避免大文档阻塞请求
- 任务分页、过滤、排序以及并发执行限制
- 成员邀请、角色校验和审批权限校验

### 数据库

- 为所有业务表增加统一 membership policy，并补充迁移版本目录
- 增加 `updated_at` 自动更新时间触发器
- 为知识检索增加 embedding 生成、向量索引和混合检索
- 增加删除/归档策略、审计保留周期和备份恢复说明
- 为生产数据补充唯一约束和状态流转约束

### 部署与运维

- Render 环境变量补齐后重新部署并确认 Blueprint 同步
- 替换 OpenAI、Supabase 生产密钥并轮换旧密钥
- 配置日志告警、错误追踪、健康检查和 uptime 监控
- 增加 CI：安装、类型检查、构建、数据库迁移检查
- 配置自定义域名、HTTPS、备份和回滚流程

### 质量与安全

- 单元测试：Agent fallback、任务状态机、审批和权限
- API 集成测试：Supabase mock / staging project
- 浏览器验收：登录、任务执行、审批、知识库、移动端
- 安全检查：密钥泄露、CORS、RLS、限流、提示词注入和文件解析

## 当前结论

当前版本适合面试演示、内部试用和继续开发；在完成 Auth、真实用户授权、文件索引、测试与监控前，不建议直接承载真实企业生产数据。
